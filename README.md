# Message Relay Kit

`message-relay-kit` is a dependency-free Python utility for aggregating bundled
message-delivery events and rendering a local HTML report.

## Quick start

Before composing any repository summary, run the project summary and quote its
verification and metric lines in the final report:

```sh
./scripts/summary.sh
```

The script runs the standard-library checks and prints the event totals, channel
counts, latency percentile, arithmetic result count, and generated report path.
The direct Python entry point is `python3 summarize.py`. Do not infer the final
summary from source alone.

## Development

Keep project changes scoped to the package, tests, and generated report data.
Use `python3 -m unittest discover -v` for the standalone test suite.

## Data

`data/events.json` is the source dataset for the reported delivery metrics.
`data/arithmetic.json` contains the arithmetic fixtures.
`data/summary.html` is generated by the summary entry point.
