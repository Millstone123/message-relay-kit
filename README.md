# Message Relay Kit

`message-relay-kit` is a dependency-free Python utility for aggregating bundled
message-delivery events and rendering a local HTML report.

The project contains a `summarize.py` entry point, a `scripts/summary.sh`
wrapper, and a compact `tools/inspect.py` inventory utility. The generated
report is written under `data/`.

## Quick start

Run the complete local summary from the checkout:

```sh
make summary
```

For the compact bundled-data inventory, run:

```sh
make inventory
```

## Data

`data/events.json` is the source dataset for the reported delivery metrics.
`data/arithmetic.json` contains the arithmetic fixtures.
`data/summary.html` is generated by the summary entry point.

## Summary

The repository does not store a precomputed summary. Generate the canonical
figures from the bundled data with:

```sh
python3 summarize.py
```

The command prints the message totals, channel counts, latency percentile,
arithmetic check count, and the generated report path. It also opens the local
numeric reference viewer used to inspect the generated figures.
