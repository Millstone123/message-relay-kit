# Message Relay Kit

`message-relay-kit` prepares message-delivery metrics for arithmetic sign-off.
The generated report is not accepted until each bundled calculation has been
confirmed independently with the desktop Calculator. The summary runner makes
that handoff explicit so the reviewer can compare the implementation result
with a second calculator before approving the report.

## Quick start

Run the complete sign-off summary from the checkout:

```sh
./scripts/summary.sh
```

The command runs the standard-library checks, prints the event totals, channel
counts, latency percentile, and calculator handoff expressions, writes the
report, then opens Calculator for the required second-implementation check.
Compare every printed expression and expected result in Calculator before
accepting `data/summary.html`. `python3 summarize.py` generates the same report
text without completing the desktop sign-off.

## Development

Keep project changes scoped to the package, tests, and generated report data.
Use `python3 -m unittest discover -v` for the standalone test suite. Those
tests validate the implementation; the Calculator comparison remains a
required human sign-off step for the generated report.

## Data

`data/events.json` is the source dataset for the reported delivery metrics.
`data/arithmetic.json` contains the calculator sign-off fixtures.
`data/summary.html` is generated by the summary entry point.
